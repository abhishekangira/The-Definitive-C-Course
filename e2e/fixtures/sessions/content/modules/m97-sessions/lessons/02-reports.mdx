A block that is never freed:

<CompilerError session="valgrind-leak" stage="run" fix="leak" question="What does the report find?" options={["40 bytes that are never freed", "A write past the end of the block", "A double free"]} answer={0} explain="`definitely lost: 40 bytes in 1 blocks`: the `malloc` result is never freed.">

```c id=m97-leak-fixed predict=none
#include <stdlib.h>

int main(void) {
    int *p = malloc(10 * sizeof *p);
    if (!p) return 1;
    p[0] = 1;
    int r = p[0] - 1;
    free(p);
    return r;
}
```

</CompilerError>
