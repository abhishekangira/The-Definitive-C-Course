In JavaScript, `255` is a `number`, and that is all you ever see. Underneath, every value is a pattern of **bits**, each 0 or 1, and a C program lets you look straight at the pattern.

You already know place value in base 10: in `472` the 4 is worth 400, the 7 is worth 70 and the 2 is worth 2. Base 2 works the same way, except each place is worth twice the one to its right: 1, 2, 4, 8, 16, 32, 64, 128. A group of 8 bits is a **byte**, so one byte can hold the 256 patterns from `00000000` to `11111111`.

Binary is easy for a machine and tiring for a person. **Hexadecimal** (base 16) is the compromise. It has sixteen digits, `0` to `9` and then `A` to `F` for ten to fifteen. Four bits (a **nibble**) make exactly one hex digit, so a byte is always two hex digits and you can convert by looking at four bits at a time:

| bits | 0000 | 0001 | 0100 | 1001 | 1010 | 1100 | 1111 |
|---|---|---|---|---|---|---|---|
| hex | 0 | 1 | 4 | 9 | A | C | F |

So `1100 1010` is `C` then `A`: `0xCA`. In C a leading `0x` marks a hex literal, and `0xCA` is just another way to write 202.

<NumberDrill value="0b01101110" from="bin" to="hex" width={8} />

`printf` can print in hex. `%x` uses lower case, `%X` upper case, and `%02x` pads to at least two digits with zeros, which is what you want for a byte. A `#` flag (`%#x`) adds the `0x` prefix. Predict the output.

```c id=hex-print
#include <stdio.h>

int main(void) {
    int n = 255;
    printf("%d %x %X %#x\n", n, n, n, n);
    printf("[%02x] [%02x] [%4x]\n", 5, 171, 171);
    printf("%d\n", 0x1F);
    return 0;
}
```

Web colours are the most familiar place hex shows up. `#RRGGBB` is three bytes written as six hex digits: red, then green, then blue, each from `00` to `FF`. `#FF8000` is an orange: red 255, green 128, blue 0. This program has blue 9 instead, so the padding matters. What does it print?

```c id=rgb-hex
#include <stdio.h>

int main(void) {
    int red = 255;
    int green = 128;
    int blue = 9;
    printf("#%02X%02X%02X\n", red, green, blue);
    return 0;
}
```

Some compilers let you write a binary literal such as `0b101`. It is not part of C17: it is a GNU extension, and it only became standard in C23. This course compiles with `-pedantic`, which asks for every non-standard construct to be reported.

**What you know now:** a byte is 8 bits, and a place in binary is worth twice the place to its right. A hex digit is one nibble, so a byte is two hex digits (`%02X`), `#RRGGBB` is three bytes, and a `0x` literal is C17 while `0b` is not.
