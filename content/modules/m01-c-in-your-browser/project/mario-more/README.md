# Mario (more comfortable)

Write `mario.c`: ask for a height from 1 to 8 (ask again otherwise) and print two right-aligned
and left-aligned pyramids separated by a two-space gap, with no trailing spaces.

- Build: `make`
- Check your work: `make test` (needs Node.js 18+)

`make test` prints a code at the end; paste it into the course page to record your progress.
