Every call gets a stack frame holding its parameters and locals. Step through this program.

<Stepper>

```c id=fx-frames trace predict=none
#include <stdio.h>

int add(int a, int b) {
    int sum = a + b;
    return sum;
}

int main(void) {
    int x = 3;
    int result = add(x, 4);
    printf("%d\n", result);
    return 0;
}
```

</Stepper>

Now fill in the frame yourself, just before `return sum;`.
