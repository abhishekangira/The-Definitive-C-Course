Source
You write C in the editor and press Run. The page sends your source text to a Web Worker.

Compile
Inside the worker, clang preprocesses and compiles your C. clang is itself a WebAssembly program, downloaded once and cached. Its warnings and errors come back to the editor.

Link
The linker joins your object code with the C library and produces main.wasm, a WebAssembly program.

Run
The page starts a fresh worker to run main.wasm. Each printf becomes a WASI fd_write call that the browser answers.

Output
The bytes appear in the output panel. scanf works the other way: the page asks you for input.

Native
Natively, the same C becomes x86-64 or arm64 machine code that your OS runs directly. A pointer is 8 bytes there, not 4.
